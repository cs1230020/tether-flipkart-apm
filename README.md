# Tether: nobody left alone after the Snap

Prototype for the Flipkart APM '29 case (Prompt 2), by Shashank Kumar, IIT Delhi.

**Live prototype:** https://cs1230020.github.io/tether-flipkart-apm/

Or download `index.html` and open it in any browser. It is plain HTML, CSS and JS, with no install and no internet needed.

Tether finds people who survived the Snap but cannot survive alone (infants, bedridden elders, home patients) whose only caregiver vanished. Every survivor is asked one question: *"Did someone you lost take care of anyone?"* The nearest verified volunteer is then sent.

The prototype has three views:
1. **Survivor:** emergency alert, check-in, marking who is gone, the one question, and help dispatched (plus a USSD version for feature phones)
2. **Responder:** prioritised task, address unlocked on accept, found, handover to a named guardian
3. **District command:** north-star metric, oldest unreached cases, escalation, and redeploying volunteers
